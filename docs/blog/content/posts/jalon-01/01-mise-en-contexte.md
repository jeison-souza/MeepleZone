## 1. Introduction

Ce document présente la mise en place de l'environnement de développement et les objectifs initiaux pour le projet du cours **INF-1410**. L'objectif principal est de structurer une documentation technique claire et rigoureuse.

## 2. Environnement technologique

Le projet est développé en utilisant les outils suivants :
* **Générateur de site statique** : Hugo (version Extended) avec le thème PaperMod.
* **Format de configuration** : YAML (`hugo.yaml`).
* **Hébergement et suivi** : Dépôt Git configuré pour le suivi des versions.

## 3. Prochaines étapes

Les prochaines phases de ce travail consisteront à :
* Définir officiellement le sujet et le concept du projet (application web).
* Définir les users stories de départ pour le projet.
* Fixer la stack technologique et valider l'architecture générale.
* Documenter l'architecture logicielle au fur et à mesure de l'avancement
